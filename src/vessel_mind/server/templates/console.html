About this demo

vessel-mind is an agent runtime. It answers questions from a fixed set of public documents (vessel-mind's own design documents and the VibeConform documentation), and it can use tools: here, one Notion page it may read but not change.

What to try

  • Ask about the design: why the agent runtime is separate from its client, how the router picks a model, how this demo is protected.
  • Ask about the Notion page: what is still open on its sprint board, what a term in its glossary means.
  • Ask it to change the Notion page. It makes a proposal that you can see; on this site every approval is refused, so nothing is written.
  • Ask in English or in Traditional Chinese.

How to read an answer

  • The badge under the question shows the route: the fast path (a small model) or the slow path (a larger model).
  • Each [n] mark links to the source passage it cites.
  • A tool card shows one tool call; open it for its input and result.
  • A proposal card shows a change the agent wants to make, with Approve and Reject.
  • Stop ends an answer that is still running. Ctrl+Enter sends the question.
